## NyayaBandhu

NyayaBandhu is a Digital Public Infrastructure (DPI) project designed to transform the discoverability and management of legislative documents in India. It builds a unifying architecture to standardize legislative text using the globally acknowledged Akoma Ntoso (XML) standard, moving away from fragmented PDF dumps to creating authentic and up to date "Living Data." The goal is to improve the efficiency of governance by providing all stakeholders with authentic legislative information right from the government.
